`axvn-hoding-common` is a **utility package** for axvn-hoding modular connectors, providing commonly used functions and helpers for working with axvn-hoding REST/WebSocket APIs. It ensures reusable and optimized utilities to streamline development.

## Installation

To use this library, ensure your environment is running Python version **3.10** or later.

```bash
pip install axvn-hoding-common
```

## Features

- **Common Utility Functions** for API requests, timestamps, and signatures.
- **Optimized for axvn-hoding Connectors** to ensure seamless integration.
- **Lightweight & Tree-Shakeable** – only imports what you need.
